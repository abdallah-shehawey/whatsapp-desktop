# Dardasha

Dardasha (دردشة, "chat") is an independent desktop client for WhatsApp Web on
Linux. It adds what a browser tab cannot: a system tray icon that shows unread
messages, native desktop notifications, global shortcuts, media controls for
voice notes and starting hidden at login. It follows the desktop's fonts and
theme, keeps Arabic and other right-to-left text in its correct direction, and
offers a passcode lock and a privacy shield that keeps message text out of
notifications.

It requires an existing WhatsApp account and an Internet connection.

Dardasha is the name this client carries in Flathub and in the Fedora and
Debian archives, which do not take the WhatsApp name or logo on a client that
WhatsApp did not make. It is built from the whatsapp-desktop project,
<https://github.com/abdallah-shehawey/whatsapp-desktop>, with `BRAND=dardasha`.
Report problems there.

Settings are kept in `~/.config/whatsapp-desktop/` and the session in
`~/.local/share/whatsapp-desktop/`, the upstream project's directories.
