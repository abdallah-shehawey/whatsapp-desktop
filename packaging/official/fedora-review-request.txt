Description:
Independent desktop client for WhatsApp Web with system tray integration,
desktop notifications, themes, configurable fonts and privacy controls. It
requires an existing WhatsApp account and Internet access. The project is not
affiliated with Meta or WhatsApp.

The application is GPL-3.0-or-later, its WhiteSur-derived artwork GPL-3.0-only,
and its AppStream metadata CC0-1.0. Artwork sources and license notices are
included in the source archive.

This source-only application proposal installs JavaScript and data and depends
on a distribution-owned Electron >= 40, < 41 runtime. It neither downloads
Electron nor runs npm during the build. The application package and tests pass
in a clean Fedora 44 environment, with zero rpmlint errors or warnings.

Runtime prerequisite:
Electron is not currently packaged in the target Fedora repositories. This
proposal does not complete Electron's source build, dependency packaging or
security maintenance and cannot currently be installed from the official
archives. I seek guidance on the runtime prerequisite and the eligibility of
this independent client; final review/acceptance must wait for these matters.
